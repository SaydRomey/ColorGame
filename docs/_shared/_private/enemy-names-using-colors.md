- Rufous Mirage:

- Sanguine Cultist:
  - sanguine literally carries the blood association.

  - madder is both a plant/root source and a historic red pigment.

Cordovan would also be useful for Vireya:  
it is an attested dark burgundy/red color whose name is associated with leather.

This region benefits enormously from obscure historical purples. 
- Byzantium is an attested dark reddish-purple, 
  with use as an English color name recorded from the early 20th century. 
- Eminence is also an established purple color name.

- Plum Dandy Fragment 
  — strange, theatrical and slightly ridiculous in exactly the way Myrrala can support.
- Violaceous Lurker — sounds biological and uncanny.
- Byzantium Matron — feels like a boss name without needing an invented fantasy adjective.
- Palatinate Purple Vowkeeper — formal, heraldic and oath-like.

## ⚫ Nullshade

Here we could deliberately change the rule slightly.  

Nullshade should use genuine achromatic, near-black, pale, transparent, 
or color-deprivation terms rather than ordinary hue names.
