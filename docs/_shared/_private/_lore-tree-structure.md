# Lore Tree Structure v2

## World
- **Shattered Realm / World**
  - **Origin**
    - Prismatic Core
    - Prismara / primal harmony
  - **Central wound**
    - Prism Wound
      - shattered center of the world
      - source site of Nullshade as Place
  - **Core metaphysical model**
    - Color as law
    - Hue Binding = active loadout
    - Hue Affinity = long-term alignment / world reaction
    - Personality = tonal / social expression of affinity
    - Mneme = spendable resource
    - Memory Echo = diegetic replay / truth scene
    - Hue Coherence = survivability / readability in deeper Nullshade
  - **Nullshade**
    - Nullshade as Place
      - late-game core region
    - Nullshade as Phenomenon
      - intrusion / exposure / desaturation leaking into all regions

## History / Timeline
- **Unified age**
  - Prismatic Core whole
  - harmony before hue fragmentation
- **Rise of the Orders**
  - hue-specialized truths become institutions
- **Color War**
  - ideological ownership of hue hardens
  - Tyrian dynasty / mixed-hue domination attempt
- **Huefall / Shattering**
  - Core breaks
  - regional hue laws become dominant
  - Prism Wound / Nullshade created
- **Post-shattering era**
  - Orders fragment
  - relics, shrines, archives, regional cultures stabilize separately
- **Dimming Cycle / present era**
  - memory instability
  - Nullshade intrusion increases
  - Prismwalker enters the story

## Player
- **Prismwalker**
  - colorless vessel / outsider / ontological exception
  - body began in the Prism Wound
  - first stable continuity began elsewhere
  - identity formed through:
    - bound hues
    - affinity
    - personality
    - artifacts
    - choices
- **Bound Hues**
  - Crimson / Red
  - Cobalt / Blue
  - Verdant / Green
  - Yellow / Golden / Aurelian
  - Violet / Purple
  - Brown / Earthen
- **Affinity tiers**
  - Initiate
  - Adept
  - Expert
  - EXPERT
- **Endgame**
  - return to Prism Wound
  - Fractured Core encounter
  - final outcomes around rebind / fracture / possible broader null-aligned branch
