# The Shattered Realm — Interactive Map Prototype

Open `index.html` in a browser.

This is a self-contained black-and-white top-down map prototype with:
- zoom and pan
- clickable regions, cities, landmarks, and causeways
- layer toggles
- approximate vector region shapes based on the original layout
- exported GeoJSON data for future Leaflet/QGIS/Tiled workflows

The map is intentionally vector-based rather than image-based.  
Edit the coordinates, labels, and layer data in `index.html` or use 
`shattered_realm_prototype.geojson` as the starting point for a proper map pipeline.
