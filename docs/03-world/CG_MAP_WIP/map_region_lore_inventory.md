
## Global / world-level map labels

Primary world terms to consider for the map: **The Realm**, **Shattered Realm**,
**Hue Realms**, **Prismatic Core**, **Prismara**, **Prism Wound**, **Prism
Gates**, **Hue Archive Fragments**, **Memory Echoes**, **Hue Coherence**,
**Mneme**, **Dimming Cycle**, **Color War**, **Huefall / Shattering**, **The
Dimming**, **The Seventh Hue**, **The Bound**, **Bound Hues**, and
**Prismwalker**.

Cross-regional map overlays: **Prism Gates** between each outer region and
Nullshade; **Nullshade exposure / Nullshade intrusion** as gray fracture zones
outside the core; **Prismatic Rift Zones** after hue instability events;
**Forgotten Orders’ Camps**; **The Spiral Mirror** as an optional hidden
dungeon; **Memory Echoes** and **Hue Archive Fragments** scattered across all
regions. The docs also list cross-regional threats such as **Nullborn Husks**,
**Hue Leeches**, **Tyrian Echo**, **Bloomrot Titan**, **Wickerborn**,
**Nullshade Revenant**, **Moth-Witch of the Verdant Spiral**, **Huefractals**,
**Memory Grafter**, **Spectral Harvester**, and **The Unhued Choir**.

A note on certainty: several names in `OVERHAUL.md` read like candidate
subregion names rather than fully locked canon, and the file itself flags
subregion/district names as incomplete. I would still use them as map-label
candidates, but tier them as “major canon,” “secondary canon,” and “candidate /
optional.”

## Biome features needed for the final image

I did not find named rivers in the retrieved docs. The closest mapable water /
flow features are: Huevale’s flooded marshes, sinkwater, flooded courtyards, and
swamp channels; Iriseld’s stormy ocean, Whispering Bay, Mirrorwake, tidal
bridges, and bioluminescent reefs; Vireya’s lava rivers and molten ravines;
Luxeran’s oases and mirage routes; Auralith’s Dustmere dead lake / ash basin and
Ochrellum alchemical marshes; Nullshade’s Shatterglass Pools; and Myrrala’s
mirrored pools.

Mountain / elevation features to draw: Iriseld’s floating islands, Skyglass
Pillars, cloud harbors, and high bridges; Vireya’s Crucible Spires, Cinnaridge,
Fauxflame Crags, volcanic valleys, and obsidian canyons; Luxeran’s Dawnspire,
wind-shaped pillars, dunes, and sun temples; Auralith’s Phylactery Rise, Ochrim
mine, fossil pits, terraces, and catacombs; Nullshade’s floating debris,
recursive stairways, and fractured crater geometry.

Forest / grove features to draw: Huevale should carry the heaviest forest mass
with living canopies, fungal forests, root labyrinths, groves, shrine gardens,
and flooded woods. Myrrala should carry a more dreamlike grove layer: twilight
gardens, mirrored groves, petal labyrinths, floating flower fields, and
silk-veiled shrine paths. Iriseld is mostly coastal / sky; Luxeran mostly desert
/ oasis; Vireya mostly volcanic / battlefield; Auralith mostly ash ruin /
catacomb.

Recommended label hierarchy for the future map: region names largest; city /
stronghold labels second; canon landmarks third; candidate subregions fourth;
enemy/NPC/scene labels as icon callouts or a separate legend so the map does not
become unreadable.
