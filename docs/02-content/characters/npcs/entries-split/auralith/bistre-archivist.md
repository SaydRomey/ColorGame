# Bistre Archivist

**Region:** 🤎 Auralith — Memory, decay, silence, alchemy  
**Role:** Caretaker of soot-stained scrolls; lorekeeper with smudged hands and perfect recall  
**Visual:** Shadow-eyed scholar with ash-covered fingers
