# Viridian Alchemist

**Region:** 🟢 Huevale - Nature, growth, alchemy, stealth  
**Role:** Master of stable transmutations; uses sacred bluish-green ink to draw power into pigments  
**Visual:** Alchemical scribe clad in bluish-green robes
