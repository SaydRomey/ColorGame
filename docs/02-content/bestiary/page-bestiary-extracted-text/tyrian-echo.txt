CLASSIFICATION

Name:
Tyrian Echo.

Type:
Spectral Memory Construct.

Threat Level:
Moderate — Emotionally volatile, disorients combat rhythm.

First Emerged:
Post-Color War Scarring.

HUE INTERACTION

Tied directly to Crimson, representing willpower and wrath, and Violet, representing dream and memory.

Mimics player attacks if emotionally resonant, such as dialogue trees about vengeance or failure.

Vulnerable to Brown, representing truth or memory anchors, and Yellow, representing disruption or light.

LOCATION TAGS

Ruined Battlegrounds.

Color-War Memorials.

Memory Glyphs.

ANATOMY / MANIFESTATION

1. VIOLET-CRIMSON SILHOUETTE

Female-form spectral outline with broken hue ribbons.

2. FLICKER LOOPS

Movement locked in repeating animation cycles.

3. SPLIT COMBAT STATE

Transitions between sword strike and spellcast mid-motion.

4. MEMORY FRACTURES

Shards that burst into alternate regrets when struck.

5. UNFINISHED ATTACK PATTERN

Always completes attacks she never visibly begins.

RESONANCE TRIGGER

Triggered by emotionally resonant states:

Vengeance.

Failure / Guilt.

Betrayal / Regret.

“The more you carry, the stronger her echo.”

DUEL RHYTHM — THE LOOP

Swordplay → Spellcast → Pause → Repeat.

BEHAVIOR PATTERN

Appears near color-war memorials, ruined battlegrounds, or memory glyphs.

Engages without provocation if the player has committed a key regret, tracked via world-state flags.

Pauses mid-battle, repeating old dialogue from other characters — none of whom are present.

Mimics emotionally resonant attacks.

The final loop intensifies into a collapsing repetition.

KNOWN WEAKNESSES

Loses form briefly when exposed to Echo Pulse or Truth Sigils.

Disrupted by reframing dialogue such as “I forgive them,” “That wasn’t me,” and similar truth / release statements.

A further release statement shown is:
“I choose differently now.”

The final phase collapses if the player stands still during her final loop.

COUNTERS

Brown — Truth Anchors.

Yellow — Light / Disruption.

Recommended tools:
Truth Sigils, Echo Pulse, Light Shard Bolts.

DESCRIPTION

Tyrian Echo manifests as a blurred violet-crimson warrior silhouette, female in form, cloaked in flickering ribbons of broken hue.

She stutters through battle patterns of a long-dead fighter, always completing attacks she never begins.

Her body glitches between swordplay and spellcasting, sometimes mid-animation.

HABITAT / MANIFESTATION

Appears near color-war memorials, ruined battlegrounds, memory glyphs, shattered shrines, and scars where Crimson wrath collided with Violet dream-memory.

BEHAVIOR / STATE FLOW

Memorial Drift → Echo Trigger → Loop Assault → Dialogue Pause → Final Repeat.

Engages without provocation if the player carries a key regret.

Mimics emotionally resonant attacks and combat rhythms.

Occasionally pauses to repeat dialogue from absent voices.

Final phase may collapse if the player stands still during her last loop.

ABILITIES / STATUS EFFECTS

REPEAT SLASH

Delayed mirrored blade strike.

SPELL GLITCH

Alternates between Crimson aggression and Violet illusion.

REGRET FRAGMENT

On hit, bursts memory shards and emotional echoes.

ECHO LOOP

Replays a prior movement pattern with slightly altered timing.

VOICE RECALL

Emits old dialogue fragments that disrupt focus.

HUE INTERACTION

Tied directly to Crimson will / wrath and Violet dream / memory.

Can mimic player attacks if emotionally resonant.

Vulnerable to Brown truth / memory anchors.

Vulnerable to Yellow disruption / light.

KNOWN WEAKNESSES

Echo Pulse destabilizes her form.

Truth Sigils briefly expose the core loop.

Reframing dialogue such as forgiveness or self-separation disrupts her aggression.

Standing still during the final loop can collapse the encounter’s last phase.
